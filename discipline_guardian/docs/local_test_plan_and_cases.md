# 本地测试计划与测试用例（开发任务三收口）

## 1. 测试目标

- 验证开发任务三的数据链路是否真实落地（非 mock）。
- 验证关键页面对 SQLite 数据的读写闭环。
- 验证构建与基础自动化测试稳定通过。

## 2. 测试范围

- 首页：使用概览与详情数据展示。
- 应用管理页：设备应用读取、添加监控、限制时长修改、删除监控。
- 统计页：周/月趋势与排行读取。
- 设置页：解锁方式、监控时段、通知设置、白名单。
- 锁屏页：密码校验、知识问答、延迟等待参数读取。

## 3. 测试环境

- OS: Windows
- Flutter: 3.x
- Dart: 3.x
- Device: Android 模拟器/真机（需可运行 `flutter run -d <deviceId>`）
- 数据库: SQLite（sqflite）

## 4. 执行顺序

1. 自动化基线检查
2. 页面数据读写联调
3. 锁屏验证链路联调
4. 回归检查

## 5. 自动化测试命令

在 `discipline_guardian/` 目录执行：

```bash
flutter analyze
flutter test
flutter build apk --debug
```

通过标准：

- `flutter analyze` 无错误
- `flutter test` 全通过
- `flutter build apk --debug` 成功产出 APK

## 6. 手工测试用例

### TC-01 添加应用页读取真实设备应用

- 前置条件: 在 Android 设备运行 App。
- 步骤:

1. 进入 `应用` 页
2. 点击 `+` 进入 `添加应用`
3. 观察应用列表

- 预期结果:
- 列表展示设备真实已安装应用（非固定 mock 列表）
- 搜索可过滤真实应用

### TC-02 添加监控应用并回到应用列表

- 前置条件: 设备应用列表可读取。
- 步骤:

1. 在 `添加应用` 选择任一应用
2. 设置每日限制并确认添加
3. 返回 `应用` 页

- 预期结果:
- 新增应用出现在监控列表
- 显示正确包名与限制时长

### TC-03 修改每日限制持久化

- 前置条件: 已有至少一个监控应用。
- 步骤:

1. 打开应用设置页
2. 调整每日限制并保存
3. 返回后重进应用设置页

- 预期结果:
- 限制值更新成功且重进后保持一致

### TC-04 删除监控应用

- 前置条件: 已有至少一个监控应用。
- 步骤:

1. 在应用设置页执行删除
2. 返回应用列表

- 预期结果:
- 应用从监控列表消失

### TC-05 首页读取数据库概览

- 前置条件: 已添加监控应用并存在使用数据。
- 步骤:

1. 进入首页
2. 查看 `应用使用概览` 和 `今日详情`

- 预期结果:
- 展示数据来自数据库聚合
- 与应用管理页数量与状态一致

### TC-06 统计页周/月切换

- 前置条件: usage_logs 中有测试数据。
- 步骤:

1. 进入统计页
2. 切换 `本周` / `本月`
3. 查看趋势和排行

- 预期结果:
- 趋势与排行随周期切换刷新
- 无数据时展示空状态，不崩溃

### TC-07 解锁方式设置持久化

- 前置条件: 进入 `我的 -> 解锁方式`。
- 步骤:

1. 选择任一解锁方式并保存
2. 返回设置页并重进

- 预期结果:
- 解锁方式显示与上次选择一致

### TC-08 监控时段设置读写

- 前置条件: 进入 `我的 -> 监控时段`。
- 步骤:

1. 调整工作日/周末时间并保存
2. 返回后重进页面

- 预期结果:
- 时间与启用状态保持为保存值

### TC-09 通知设置读写

- 前置条件: 进入 `我的 -> 通知设置`。
- 步骤:

1. 调整提醒开关和提前分钟并保存
2. 返回后重进页面

- 预期结果:
- 页面状态与保存值一致

### TC-10 白名单设置读写

- 前置条件: 进入 `我的 -> 白名单`。
- 步骤:

1. 开启/关闭白名单开关
2. 添加白名单应用
3. 移除白名单应用

- 预期结果:
- 开关和列表变更均持久化
- 重进页面仍保持一致

### TC-11 锁屏密码校验读取配置

- 前置条件: 已设置密码值（默认回退 123456）。
- 步骤:

1. 触发锁屏（密码模式）
2. 输入错误密码
3. 输入正确密码

- 预期结果:
- 错误密码提示并扣减次数
- 正确密码可解锁

### TC-12 锁屏知识问答读取题库

- 前置条件: 题库中存在填空题。
- 步骤:

1. 触发锁屏（知识问答模式）
2. 连续答题

- 预期结果:
- 题目来自当前题库
- 连续答对达到阈值可解锁

### TC-13 锁屏延迟等待读取配置

- 前置条件: 已设置 delay_minutes。
- 步骤:

1. 触发锁屏（延迟等待模式）
2. 观察倒计时长度

- 预期结果:
- 倒计时与 `delay_minutes` 一致
