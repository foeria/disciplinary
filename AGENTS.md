# Project Agent Notes

## Shell Preference

- Prefer PowerShell 7 for terminal commands in this repository.
- On this machine, invoke PowerShell 7 with `C:\Program Files\PowerShell\7\pwsh.exe`.
- When needed, use `-NoProfile` to avoid local profile execution-policy issues.
- If the default session is Windows PowerShell 5.1, explicitly launch PowerShell 7 for command execution instead of relying on `pwsh` being on `PATH`.
